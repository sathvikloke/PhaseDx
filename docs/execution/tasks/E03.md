## Execution

1. Resolve packages actually used, including DICOM decoding, numerical libraries and inference dependencies; retain Python/platform versions and model serialization compatibility.
2. Separate CPU metadata/scoring dependencies from torch/device dependencies; avoid an unnecessary CUDA installation on the Mac.
3. Use isolated environments and check imports and tiny synthetic I/O, without updating the user-wide environment or running training.
4. Document unsupported codecs/device behavior as exact dependency failures.

## Acceptance

A fresh environment can import the declared modules and parse a synthetic object. Version pins describe a tested installation, not a guessed list.

Resource profile: setup / bounded disk. Actual runtime is unknown until measured; no invented nine-hour compute estimate.

Return: exact command and environment, input/config identities, output locations, exit status, failures and measured timing. Mark execution complete only with evidence; scientific acceptance is separate. If one input is missing, name it and backfill another ready task.
