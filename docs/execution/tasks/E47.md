Owner: **User / authorized CPU executor (Codex or independently launched Claude)**. Lane: conditional historical. Priority: conditional. Status: optional.

Dependencies: [E36](E36.md), [H01](H01.md).

## Inputs

Resolve batch locators through [source map](../source_map.json) and [input configuration](../INPUTS.md). Historical inputs are read-only.

## Deliverables and owned paths

## Execution

1. Prefer locating existing immutable results over recomputation.
2. If truly missing and scientifically retained, execute only the named original script/config for that benchmark; do not run pipeline/run_all.py --force.
3. Preserve task/metric distinctions: LUNA FROC versus AUROC, PI-CAI case versus lesion, Duke within-cancer localization, and metadata versus pixels.
4. No full architecture sweep, new training or retrospective registration is authorized by this task.

## Acceptance

One specified retained evidence gap is closed, or irrecoverability is documented. Historical-only claims do not trigger execution.

Resource profile: dataset-specific; bounded before run. Actual runtime is unknown until measured; no invented nine-hour compute estimate.

**Conditional scope:** do not schedule automatically. Record the scientific/operational reason and activate only this task when that condition actually exists.

Return: exact command and environment, input/config identities, output locations, exit status, failures and measured timing. Mark execution complete only with evidence; scientific acceptance is separate. If one input is missing, name it and backfill another ready task.
