Owner: **User / authorized CPU executor (Codex or independently launched Claude)**. Lane: release. Priority: parallel. Status: blocked.

Dependencies: [E43](E43.md), [E44](E44.md), [H14](H14.md).

## Inputs

Human-approved public release manifest and repository/archive destination

Resolve batch locators through [source map](../source_map.json) and [input configuration](../INPUTS.md). Historical inputs are read-only.

## Deliverables and owned paths

Tag/commit or archive receipt, citation metadata and persistent links

## Execution

1. Publish only the approved artifact set and record the exact content identity.
2. Do not upload source imaging, individual labels or personally identifying author forms.
3. A GitHub code release is separate from a journal submission; do not submit the manuscript or accept agreements for the user.
4. Update links mechanically in approved documents and retain the final version.

## Acceptance

Approved public artifact links resolve and match the release manifest; no implied journal acceptance.

Resource profile: network upload after explicit approval. Actual runtime is unknown until measured; no invented nine-hour compute estimate.

Return: exact command and environment, input/config identities, output locations, exit status, failures and measured timing. Mark execution complete only with evidence; scientific acceptance is separate. If one input is missing, name it and backfill another ready task.

## Completion evidence

- Requires applicable external result/scientific approval, author or release-permission inputs. Existing reading PDF is not final submission evidence. No publication or weight redistribution authorized by code push.
