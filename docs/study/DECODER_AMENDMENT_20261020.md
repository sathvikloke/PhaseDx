# Outcome-blind decoder extension

Adjudicated October 20, 2026, before CQ500 model predictions or reference-outcome rows were opened in this session. The user authorized all dependency-ready CPU work. This addresses the Batch31 JPEG-Lossless technical limitation; it changes input decoding support, not the endpoint, network parameters or clinical series requirements.

Permit JPEG Lossless Process 14 SV1 (DICOM transfer syntax UID 1.2.840.10008.1.2.4.70) through pylibjpeg 2.1.0 / pylibjpeg-libjpeg 2.3.0 with pydicom 3.0.2. Keep the previously permitted uncompressed syntaxes. Reject declared lossy compression and unsupported transfer syntaxes. Retain failures rather than converting them into successful inputs. The actual decoder/adapter source hashes and package versions must enter the design and execution identities.

Evidence: four fixed synthetic signed/unsigned 12-/16-bit fixtures matched known stored pixels through pylibjpeg and independent GDCM. A prelocked 16-file source diagnostic, sampled by existing inventory order rather than labels or scores, produced 12 compressed-image exact stored-pixel and HU agreements, four uncompressed skips and no mismatches. The sample was not expanded after those results. This verifies those decoded inputs only; it does not prove whole-cohort reliability.

Preserve the downstream HU conversion, canonical three-window/resize recipe, float16 storage round trip, float32 normalization, frozen checkpoint and maximum-logit aggregation. Original recipe bytes remain unchanged. No refitting, calibration, random draws or clinical result is introduced by this amendment.

Rebuild technical metadata under the explicit `lossless_sv1_pylibjpeg_v1` policy. Do not count an unavailable drive or source-identity mismatch as an unusable examination. Clinical compatibility remains distinct: unresolved noncontrast, axial, soft-reconstruction or full-brain coverage status cannot be silently marked qualified. The amendment does not assert that all 870 previously unsupported series are now valid or that any examination is clinically selected.
